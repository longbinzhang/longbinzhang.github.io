# Longbin Zhang — Academic Website

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder (not the outer ZIP).
3. Go to repository **Settings → Pages** and choose **Deploy from a branch**, `main`, `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/` after deployment.

## Edit
- `index.html`: all page text, links, publications and projects.
- `style.css`: colors, layout, fonts, mobile styling.
- `assets/profile.jpg`: replace with a new photo, retaining filename.
- `assets/CV_Longbin_Zhang.pdf`: replace to update the CV download.

Edit files directly in GitHub by clicking a file and the pencil icon, then **Commit changes**. Changes are published automatically.

This is a starter website; review biographical details and project entries before publishing.
